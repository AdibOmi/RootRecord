## Q&A

**Q:** 🟢 Why does `build` run `tsc -b` before `vite build`?

**A:** Vite (esbuild) strips types without checking them; `tsc -b` fails the build on type errors first
(`package.json:8`).

**Q:** 🟡 Why are there three tsconfig files?

**A:** Browser code and Node config files need different environments (DOM vs Node types, different
libs). Project references let `tsc -b` check both with the right settings (`tsconfig.json:3`).

**Q:** 🟡 Why is `typescript` pinned with `~5.8` while others use `^`?

**A:** TypeScript minor versions can introduce new type errors; `~` allows only patch updates.

**Q:** 🟢 What does `npm ci` do differently from `npm install`?

**A:** Installs exactly the lockfile versions, deletes existing `node_modules` first, and fails if
`package.json` and the lockfile disagree — reproducible.

**Q:** 🔴 What's needed to serve this frontend in production?

**A:** `npm run build` → static `dist/`; a web server (nginx/Caddy) that serves files with long cache
headers for hashed assets, falls back to `index.html` for client routes, and proxies `/api` to the
backend (to keep same-origin cookies). None of that is in the repo yet.

**Q:** 🟡 What is `components.json` used for at runtime?

**A:** Nothing — it's configuration for the shadcn CLI that generates components into
`src/components/ui`.
